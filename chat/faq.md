## Q: Why does he build things from scratch instead of using existing frameworks?

Because a lot of the systems he's built — like an autonomous Windows event monitor at Unisys, or the custom FedProxFairness aggregation strategy in CipherCare — didn't have an existing framework that fit, so designing the architecture from zero gave him full control and no dead weight from generic abstractions.
